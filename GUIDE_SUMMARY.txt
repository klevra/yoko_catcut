🚀 실행 방법 (3가지)
═══════════════════════════════════════════════════════════════════════════════

1️⃣  가장 쉬운 방법 (GUI - 권장!)
    ┌─────────────────────────────────────────────────────┐
    │ 1. Finder에서 yoko_catcut 폴더 열기               │
    │ 2. start.command 파일 더블클릭                      │
    │ 3. 자동으로 브라우저가 http://localhost:3000 열림   │
    │ 4. 완료! ✅                                         │
    └─────────────────────────────────────────────────────┘
    소요 시간: 30초 (첫 실행은 5-10분)

2️⃣  터미널 방법
    ┌─────────────────────────────────────────────────────┐
    │ $ cd /Users/klevra/Documents/yoko_catcut            │
    │ $ docker compose up --build                         │
    │ → 브라우저에서 http://localhost:3000 수동으로 열기  │
    └─────────────────────────────────────────────────────┘

3️⃣  개발 모드 (개발자용)
    ┌─────────────────────────────────────────────────────┐
    │ Backend:                                            │
    │ $ cd backend                                        │
    │ $ pip install -r requirements.txt                  │
    │ $ uvicorn app.main:app --reload                    │
    │                                                     │
    │ Frontend (다른 터미널):                             │
    │ $ cd frontend                                       │
    │ $ npm install && npm run dev                        │
    └─────────────────────────────────────────────────────┘


🛑 중지 방법
═════════════════════════════════════════════════════════════════════════════

1️⃣  GUI 방법 (권장)

    → docker compose down

3️⃣  강제 중지

❓ 자주 묻는 질문
═════════════════════════════════════════════════════════════════════════════

Q: 처음 실행이 너무 오래 걸려요.
A: 첫 실행은 Docker 이미지를 빌드하므로 5-10분 소요됩니다.
   이후 실행은 30초 정도입니다.

Q: Docker가 없으면 어떻게 하나요?
A: SETUP.md의 "Docker Desktop 설치" 섹션을 참조하세요.

Q: 포트가 이미 사용 중이라고 나와요.
A: SETUP.md의 "포트 충돌 해결" 섹션을 참조하세요.

Q: 브라우저가 자동으로 안 열려요.
A: 수동으로 http://localhost:3000을 브라우저에 입력하세요.

Q: 파일은 어디에 저장되나요?
A: ./workspace 폴더에 저장됩니다.

Q: 여러 명이 동시에 사용 가능한가요?
A: v0.1.1은 단일 사용자입니다. v1.0.0에서 다중 사용자 지원.

Q: 로컬 외에 클라우드도 지원하나요?
A: v0.1.1은 로컬과 NAS만 지원합니다.
   v1.0.0에서 클라우드 스토리지 추가 예정.
