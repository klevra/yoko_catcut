# Yoko CatCut Release v0.1.2

Release date: 2026-06-04

Summary:
- This release makes configuration non-hardcoded and environment-driven to improve flexibility when running via Docker.
- It introduces `.env.example`, `application.yml.template`, and updates `start.command`/`stop.command` and `docker-compose.yml` to use environment variables for ports and container names.

Breaking changes:
- `application.yml` may be regenerated by `start.command` from `application.yml.template`; do not commit local `application.yml` changes if you rely on `.env` overrides.

Files changed (high level):
- `.env.example`, `.env` (local), `application.yml.template`
- `docker-compose.yml`, `start.command`, `stop.command`
- `manual.txt`, `CHANGELOG.md`, `docs/releases/v0.1.2.md`

How to use:
1. Copy `.env.example` to `.env` and edit ports or container names as needed.

```bash
cp .env.example .env
# edit .env
./start.command
```

2. To stop and remove containers:

```bash
./stop.command
```
