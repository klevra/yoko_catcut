🚀 가장 빠른 실행 방법 (1단계!)
═════════════════════════════════════════════════════════════════════════════

macOS 사용자:

  1️⃣  Finder 열기
  
  2️⃣  yoko_catcut 폴더로 이동
     (아마 ~/Documents/yoko_catcut)
  
  3️⃣  start.command 파일 더블클릭
  
  4️⃣  자동으로 브라우저가 열립니다!
       http://localhost:3000
  
  ✅ 끝!

Windows 사용자:

  1️⃣  PowerShell 열기
  
  2️⃣  다음 명령 실행:
     cd C:\Users\[사용자명]\Documents\yoko_catcut
     .\start.command
  
  3️⃣  브라우저에서 http://localhost:3000 접속
  
  ✅ 끝!

Linux 사용자:

  1️⃣  터미널 열기
  
  2️⃣  다음 명령 실행:
     cd ~/Documents/yoko_catcut
     ./start.command
  
  3️⃣  브라우저에서 http://localhost:3000 접속
  
  ✅ 끝!

🎯 첫 번째 단계별 가이드
═════════════════════════════════════════════════════════════════════════════

1. Docker 확인
   ✓ Docker Desktop이 설치되어 있나요?
   ✓ Docker 애플리케이션이 실행 중인가요?
   
   → 아니면 SETUP.md의 "Docker Desktop 설치" 섹션 참조

2. start.command 실행
   ✓ 아이콘을 더블클릭하면 됩니다
   ✓ 보안 경고가 나오면 "열기" 클릭
   
   → SETUP.md의 "보안 경고 우회" 섹션 참조

3. 브라우저 확인
   ✓ 자동으로 http://localhost:3000 열림
   ✓ "Yoko CatCut" 제목이 보이면 성공!
   
   → 안 열리면 SETUP.md의 "브라우저 문제" 섹션 참조

4. 첫 프로젝트 생성
   ✓ 왼쪽에 "New Project" 섹션
   ✓ 프로젝트 이름 입력
   ✓ "Create Project" 클릭
   
   → 축하합니다! 성공했습니다! 🎉
